# Athena resource desk — 8 October 2026

Owner-authorized functional slice at `/auth/prototypes/athena-world`. Both world NPCs and the focused directory open the same resource component. The daily board remains a labelled sample; this is not a claim that Athena is ready for a real-family pilot.

## Working behavior

- Browse 22 specific public resources across five domains. English and ten foreign languages each have a checked starter link; some child-age/language cells deliberately have no matches. Original material opens at its publisher. All starter items are free at inspection; search results have unknown access until checked.
- Five story cards have attributed CC BY source covers. Other cards explicitly say Athena cover; they are not fabricated resource thumbnails. See `ATHENA_RESOURCE_SOURCES.md` for each page, age basis and media limitations.
- Choose a browsing age band and language; these stay in memory across buildings/mode switches for the current page session. No child ability is inferred. Questions, selected resources and explanations clear when the desk closes.
- Ask a guide using typed text or English voice. Browser recording is capped at 60 seconds; finish/cancel releases microphone tracks. Status preflight checks Guide access before requesting the microphone. Audio goes only to the existing server endpoint and Deepgram, with `mip_opt_out=true`; the app does not save it. The returned transcript is editable and is never automatically sent as a search. Overlong search transcripts stay visible with a request to shorten them. Two failures invite typing; typing is always available.
- Live resource search uses Tavily and explicitly includes the selected age band/domain/language. It does not silently attach saved family context. Results are discovery leads, not verified age-fit recommendations. Requests are bounded and return at most five results.
- Source explanation extracts the selected public URL through Tavily, then sends available text and the question to the existing Nebius model. A response cites server-numbered passages; invalid IDs and malformed/blank answers fail closed. Excerpts are copied from the source, at most 24 words total. The model is instructed not to invent activities or summarize unseen video. Valid citations do not prove semantic/clinical accuracy. Missing source content produces a clear refusal, not a fabricated summary.

## Access, consent and accounting

New `/api/athena/status`, `/resources` and `/voice` routes check same-origin requests, signed-in membership and caregiver/owner role. Provider dispatch and response delivery recheck membership and the versioned family Guide switch. Extra per-request disclosure covers Tavily, Deepgram and Nebius separately. Existing AI-off settings are respected; no real family's setting was changed.

The existing durable `guide_request_reservations` RPCs provide the shared rolling allowance of 20 requests per user per 24 hours. Search and transcription each use one reservation/dispatch. Explanation uses one reservation with two dispatches (extract, then model); model retries are disabled for this operation. Failed/abandoned work still counts; accounting is metadata-only, not provider billing proof. This conservative shared limit may need separate provider allowances in a later migration. Existing production Guide callers retain their default timeout/retry behavior. Source explanation alone has a 40-second model timeout. The earlier `/discovery` endpoint remains staged/off by default.

Settings text now describes the separate resource-desk consent. The old preference version remains a master switch, not implicit authorization to send material to additional providers. Nebius/Tavily retention beyond the existing disclosure is not newly certified. [Deepgram's published data policy](https://developers.deepgram.com/trust-security/your-data) documents its opt-out; request construction was tested. No raw audio, questions or source answers are written by these routes to app tables.
